MQTT broker–

Keep the subscriber running whenever the chassis power switch is ON. It holds the car still when no commands arrive. Shutdown order: stop driving → switch power OFF → stop subscriber.

Rules

  • Run exactly one pwm_subscriber, and only this UI (or one script) sending commands.
  • Only one browser can drive at a time. Taking control from another browser takes it over.
  • If the browser stops sending for 0.3 s, the car stops. pwm_subscriber also idles after 0.5 s.
